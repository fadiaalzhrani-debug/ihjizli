# احجزلي

منصة مستقلة تبيعها احجزلي للمحلات: أتمتة كاملة لطلبات الواتساب على رقم كل عميل. الرد، الموقع، الموعد، التأكيد، التنبيه، التذكير، الفاتورة، والدفع تصير لحالها بدون موظف.

## الروابط

| الصفحة | الرابط |
|---|---|
| الموقع العام ونموذج الاشتراك | https://fadiaalzhrani-debug.github.io/ihjizli/ |
| لوحتي (المدير) | `admin.html#k=<رابط خاص>` |
| لوحة المنشأة | `biz.html#k=<رابط المالك>` |
| لوحة الموظف | `staff.html#k=<رابط الموظف>` |
| محاكي الواتساب | `sim.html?b=<slug>&k=<sim_key>` |
| صفحة الفاتورة والدفع | `pay.html?t=<رمز الفاتورة>` |

الدخول للوحات بروابط خاصة بدون كلمات مرور. كل رابط له مستخدم Supabase خاص، وإلغاؤه يقطع صلاحياته فورًا.

## البنية

```
docs/                صفحات GitHub Pages (المنشورة)
  index.html         الموقع العام (يُبنى من site-src)
  admin.html         لوحتي (يُبنى من site-src)
  biz.html           لوحة المنشأة
  staff.html         لوحة الموظف
  sim.html           محاكي الواتساب
  pay.html           الفاتورة والدفع للعميل
  assets/            التصميم المشترك ihj.css وأدوات ihj.js
site-src/            مصدر الموقع العام ولوحتي ودليل البيع
supabase/
  migrations/        الجداول وRLS والحجز والمهام
  functions/
    wa/              ويبهوك واتساب لكل المنشآت + المحاكي
    api/             أوامر اللوحات والدخول بالروابط
    pay/             ميسر والدفع التجريبي وصفحة الفاتورة
    cron/            التذكير، التصدير، رجوع البوت، متابعة ميسر (كل دقيقة)
    lead/            نموذج الاشتراك في الموقع
    _shared/         البوت، الإرسال، الفاتورة PDF، الدفع، التواريخ
tools/               أدوات التشغيل (SQL، البناء، اللقطات)
tests/               الفحوصات الآلية
```

## التشغيل

```bash
node tools/build.mjs                 # يبني docs/index.html و docs/admin.html
node tools/serve.mjs                 # http://localhost:5610/
supabase functions deploy wa api pay cron lead --project-ref kvreqxdgjeietzsfamei
node tests/e2e.mjs                   # فحوصات الخادم من الطرف للطرف
node tests/e2e-ui.mjs                # منشأة جديدة من لوحتي ثم حجز ودفع من المحاكي
```

## مبادئ

- كل جدول بيانات فيه `business_id` وRLS تفصل المنشآت. الأسرار (مفاتيح الواتساب وميسر) في `business_secrets` ولا يقرؤها إلا الخادم.
- المحاكي يمر بنفس منطق البوت الحقيقي، وما يرسل لأي رقم.
- الدفع الحقيقي فقط بحساب ميسر الخاص بكل منشأة. المنشآت التجريبية تدفع بوضع تجريبي بدون فلوس.
- خط الفاتورة IBM Plex Sans Arabic برخصة OFL (assets/fonts/OFL.txt).
